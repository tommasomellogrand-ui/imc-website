# Gateway GW001–GW015

GW010 is assigned to Custom / Sql1956795_3 for all importer repositories.
GW001–GW009 retain their existing assignments.
GW011–GW015 are supported by validation but intentionally unassigned. Requests return unsupported_game_world until their destination is configured.

Standard and explicit importer routes use the same private configuration. No tables or imported rows are modified by this change.
