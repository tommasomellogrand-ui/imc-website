ASTA DI MERCATO - INSTALLAZIONE ARUBA

1. Estrai il contenuto dello ZIP.
2. Nella directory principale di www.italianmastersclub.it crea la cartella "asta-mercato".
3. Carica dentro quella cartella il CONTENUTO della cartella "asta-mercato" presente nello ZIP.
4. Assicurati che la cartella "data" abbia permessi di scrittura (normalmente 775).
5. Apri https://www.italianmastersclub.it/asta-mercato/

Requisiti: hosting Linux con PHP 7.4 o superiore.
I prezzi e i giocatori si modificano nel file config.php.
Le offerte vengono salvate in data/auctions.json, protetto da accesso web.
